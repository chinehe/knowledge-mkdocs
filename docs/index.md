## 欢迎来到 ChineHe 的技术知识库

这是一个系统性整理技术学习笔记的个人知识库，涵盖后端开发、AI、数据库等多个方向。所有内容均为学习过程中的总结与实践记录，持续更新中。

### 知识板块

#### 🐹 Golang

从语言基础到并发编程，再到 Gin Web 框架的实战应用：

- **语言基础** — 数据类型、函数、结构体、接口、异常处理等核心语法
- **并发编程** — Goroutine、Channel、sync 包、Context、定时器
- **Gin 框架** — 路由、中间件、请求响应、模板渲染、文件处理、数据库集成

#### 🐍 Python

Python 语言基础系列，覆盖从入门到面向对象编程：

- 基础语法、流程控制、数据结构
- 输入输出、错误与异常处理
- 类与面向对象、标准库、虚拟环境与包管理

#### 🤖 AI

大模型与 AI 工程化相关内容：

- AI 大模型领域核心概念梳理
- MCP（Model Context Protocol）协议详解
- 大模型零基础入门学习笔记

#### 🗄️ 数据库与缓存

Redis 全系列深度学习笔记：

- **入门篇** — 简介、安装配置、客户端连接
- **基础篇** — 键操作、事务、发布订阅、Pipeline、Lua 脚本
- **数据类型篇** — Strings、Lists、Hashes、Sets、Sorted Sets、Stream、JSON

#### ☸️ DevOps

- Kubernetes（规划中）

### 快速开始

如果你想在本地运行这个站点：

```bash
## 安装依赖
python3 -m pip install mkdocs mkdocs-material

## 启动本地预览（支持热重载）
mkdocs serve
```

访问 [http://127.0.0.1:8000](http://127.0.0.1:8000) 即可浏览。
